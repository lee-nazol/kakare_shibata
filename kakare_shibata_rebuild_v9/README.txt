かかれ柴田！ 鬼柴田戦記 v4

【起動方法】
index.html をブラウザで開いてください。

【ゲーム開始の流れ】
1. タイトル画面で「出陣」
2. ゲームの目的・内容を確認
3. 「陣立へ」
4. コンフィグでキーを割り当て
5. 「この陣立で出陣」
6. 第一陣へ

【基本ルール】
・敵陣へ前進するほど士気が上がります。
・後退しすぎると士気が下がります。
・通常時はアクションボタンで斬撃。
・士気MAX時は同じアクションボタンで「かかれ柴田！」が発動し、味方が総突撃します。
・第二陣以降に水瓶が1個、ランダムな位置に出現します。
・水瓶は勝家自身の斬撃で破壊できます。
・瓶を割ると、その陣では回復不能になる代わり、攻撃力・移動速度・士気上昇が強化されます。
・第一〜第三陣に秒数制限はありません。
・最終陣「北庄城」は倒れるまで戦うサバイバルです。

【初期キー】
上：W
下：S
左：A
右：D
斬撃 / かかれ柴田：SPACE
一時停止：P

キーはゲーム開始前の「陣立」で変更できます。

【素材】
images フォルダ内のドット絵は本作向けに作成したオリジナル素材です。
特定の既存ゲーム作品のキャラクター、UI、ロゴ、音源等は使用していません。

討取100人以下=30、900人以上=100。101〜899人はこの間を段階的に補間。号令・瓶割り・生存時間は記録表示のみで、鬼柴田度の満点を押し上げません。
